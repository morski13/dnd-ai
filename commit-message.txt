Faster rolls online: server next to the database, fewer waits per tap

- vercel.json: functions run in Frankfurt (fra1), next to the Supabase database,
  instead of Vercel's default Washington (iad1). Every database call no longer crosses the Atlantic.
  docs/DEPLOY.md: how to check the Supabase region and which Vercel region matches it.
- rollForCharacter: the character save, live session, target, "is DM" and auto-apply lookups
  go to the database together instead of one after another (one wait instead of five).
- rollQuick: the same roll without a page render inside the answer. The character sheet and the
  Session turn card use it and refresh the page in the background after the dice land.
- loadCharacter: equipped gear (and its SRD items) loads at the same time as the character.
- Session Realtime: your own new rolls no longer trigger a second refresh
  (the screen you rolled from already refreshes once).
